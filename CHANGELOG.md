# Version history

## 1.108 — 2026-10-07

- Removed the Commodore logo glyph at U+E000 from the font, editable outlines, reference maps, preview, and download package.
- Rebuilt the font files and specimen images without that glyph. Other character mappings remain unchanged.
- Dedicated the author's contributions to the public domain under CC0 1.0 Universal, and set the font embedding flag and metadata accordingly.

## 1.107 — 2026-10-05

- Added all 63 PETSCII graphic key-front legends as smooth vector outlines, with thin cell frames and an unframed pi.
- Added a picker arranged by key to the HTML preview and a PETSCII reference-sheet image.
- Documented PETSCII bytes, screen codes, Unicode equivalents, and the font's private-use encoding in a machine-readable map and an encoding guide.
- Extended TTF, OTF, and WOFF2 validation for PETSCII coverage and cell alignment.
- Updated the download package with the new outlines, scripts, specimens, and documentation.

Existing letter, function-key, and special-label mappings remain compatible. PETSCII print proportions and stroke weights are inferred; symbol identities and key assignments follow the documented C64 uppercase/graphics layout.

## 1.106 — 2026-10-05

- Refined C, G, £, and the Commodore logo against sharper camera photographs.
- Preserved all 65 newer camera traces separately from the original traces.
- Added source-review metadata and a comparison sheet for the updated outlines.

Earlier changes are recorded in the Git history.
